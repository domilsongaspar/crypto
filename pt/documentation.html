Cryptografia

Para criptografar uma informacão Crypto fornece uma classe chamada CryptoRequest, segue a sintaxe abaixo para utilizar esta classe.

<span id="target"><span/>
var request = new CryptoRequest();
var target = document.getElementById('target');

request.send( function (res) {
target.innerText = res;
}, `lk=${text}&ce=${ce}&pr=${pr}&sd=1`);

Onde:

  • lk é a informacão para criptografar.
  • ce é o código da sua criptografia.
  • pr é o ID da sua conta.
  • sd representa o envio da requisição.
  • res é a variável com o resultado da requisição.
