O que é o Crypto?

Crypto é uma Aplicação Web que o permite criar a sua própria criptografia rápida e segura. Ele tem uma API que serve para aumentar a segurança e ajudar você a utilizar a sua criptografia criada com o Crypto no seu website ou outra aplicação.

Para que é utilizado o Crypto?

Crypto é utilizado para criptografar dados em websites ou outras aplicações, você pode alterar seus dados para mantê-los seguros de pessoas mal-intencionadas. Você pode aplicar o Crypto em palavras-passe por exemplo ou em e-mails…

Quem pode utilizar o Crypto?

Qualquer pessoa que esteja procurando por uma outra maneira de proteger seus dados com hashes ou criptografias, sendo mais específico, Crypto é para pessoas que estão procurando por uma criptografia apenas para seus sistemas.

Como funciona?

Crypto recebe uma informação e substitui cada uma das letras desta informação por um texto de nove (9) caracteres formados por letras, números e outros caracteres.

Ex.: A = $3P0+71B4

Este método permite que pessoas mal-intencionadas criem um dicionário para a sua criptografia, quebrando a sua segurança. Para resolver este problema Crypto conta com uma API que altera o código de cada caractere no seu sistema de criptografia, bloqueando a possibilidade da criação de dicionários e deixando o seu sistema de criptografia mais seguro.

Porque eu deveria utilizar o Crypto?

Nós temos muitos motivos para utilizar o Crypto começando por ele ser rápido e seguro. O Crypto dá-nos uma criptografia apenas para nós e mais ninguém, esta criptografia é fácil de utilizar sendo necessário algum conhecimento básico da popular linguagem de programação JavaScript, além disso, nós podemos utilizar esta criptografia em qualquer um dos nossos projectos.
