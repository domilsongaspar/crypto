Encrypt

To encrypt a data Crypto gives a class called CryptoRequest, follow the sintax bellow to use this class.

<span id="target"><span/>
var request = new CryptoRequest();
var target = document.getElementById('target');

request.send( function (res) {
target.innerText = res;
}, `lk=${text}&ce=${ce}&pr=${pr}&sd=1`);

Where:

  • lk is the data to encrypt.
  • ce is the code of your cryptography.
  • pr is your acoount ID.
  • sd represents the send of request.
  • res is a variable with the request result.
