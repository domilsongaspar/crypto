WHAT'S CRYPTO?

Crypto is a WebApplication that allow you to make your own safe and fast cryptography. It has a API to help it to give security and to help you to use your Crypto cryptography in your Website.

Read session about for more.

WHY SHOULD I USE CRYPTO?

We have many reasons to use Crypto starting by it be safe and fast. Crypto give us a cryptography just for us and nobody else, this cryptography is easy to use being needy some basic knowledge of popular programming language JavaScript, moreover, we can use this cryptography on any of our projects.

  • Fast
  • Safe
  • Easy to use
HOW DOES IT WORK?

Crypto gets a data and replace each letter of this data by a text of nine (9) characters formed by letters, numbers and other characters.

Ex.: A = $3P0+71B4

This method allows the malicious people to make a dictionary of your cryptography, broking your security. To fix this problem Crypto has a API that change the code of each character on your cryptography system, blocking the possibility of creation of dictionary and letting your cryptography system more safe.
